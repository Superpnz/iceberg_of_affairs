# ❄️ Iceberg of Affairs / ⛰️ Айсберг дел

Красивый и удобный список задач с оригинальным дизайном в виде айсберга / Beautiful and convenient to-do list with original iceberg design.

`JavaScript` `CSS3` `Drag & Drop` `Local Storage` | [🌐 Демо / Live Demo](https://superpnz.github.io/iceberg_of_affairs/)

## 🧊 Ключевые особенности / Key Features
* **🏔️ Уникальный интерфейс в стиле айсберга** / Unique iceberg-themed user interface
* **👆 Функциональность Drag & Drop для задач** / Drag & Drop functionality for tasks
* **💾 Сохранение данных в Local Storage** / Data persistence using Local Storage
* **🎨 Современный CSS с анимациями** / Modern CSS with smooth animations
* **📱 Адаптивный дизайн** / Responsive design

## 🏗️ Структура проекта / Project Structure
Приложение-метафора, где постепенное решение сложных задач визуализируется как таяние айсберга / A metaphorical app where gradually tackling complex tasks is visualized as the iceberg melting away.
